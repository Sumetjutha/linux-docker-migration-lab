2. Root Directory

Root คือจุดเริ่มต้นของทุก Path

ตัวอย่าง

/production/input/customer.csv

Path นี้เริ่มจาก

/

ก่อนเสมอ

3. Linux ใช้ /

Windows

D:\Production\Input

Linux

/production/input
4. Linux Case Sensitive
booking.csv
Booking.csv
BOOKING.csv

Linux มองเป็น 3 ไฟล์

5. Parent Directory

ตัวอย่าง

/xxx/yyy/file.csv

Parent Directory คือ

/xxx/yyy
