# Lesson 03 : Navigation 🚶‍♂️

## 🎯 เป้าหมาย

เรียนรู้การย้ายตำแหน่งใน Linux

---

## 📌 cd

Change Directory

ภาษาคน:

ย้ายที่ยืน

ตัวอย่าง

cd archive

ผลลัพธ์

/production/archive

---

## 📌 .

Current Directory

หมายถึง

ตำแหน่งที่เรายืนอยู่ตอนนี้

ตัวอย่าง

ปัจจุบันอยู่ที่

/etl/input

ดังนั้น

.

ก็คือ

/etl/input

---

## 📌 ..

Parent Directory

หมายถึง

ถอยกลับ 1 ชั้น

ตัวอย่าง

ปัจจุบันอยู่ที่

/etl/input/archive

คำสั่ง

cd ..

ผลลัพธ์

/etl/input

---

## 📌 /

Root Directory

จุดเริ่มต้นของ Linux ทั้งระบบ

คำสั่ง

cd /

ผลลัพธ์

/

---

## 📌 ~

Home Directory

กลับบ้าน

ตัวอย่าง

cd ~

ผลลัพธ์

/home/tik

---

## 🧠 จำง่ายๆ

cd foldername

= เข้า Folder

cd ..

= ถอย 1 ชั้น

cd /

= กลับ Root

cd ~

= กลับ Home

.

= ตำแหน่งปัจจุบัน

..

= Parent Directory

---

## 🔥 Cheat Sheet

| Symbol | ความหมาย          |
| ------ | ----------------- |
| .      | Current Directory |
| ..     | Parent Directory  |
| /      | Root Directory    |
| ~      | Home Directory    |

---

## 🎯 Summary

cd ใช้เปลี่ยนตำแหน่งการทำงาน

. คือจุดที่ยืนอยู่

.. คือถอยกลับ 1 ชั้น

/ คือ Root

~ คือ Home
